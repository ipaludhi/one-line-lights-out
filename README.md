The saddest status update an AI posts when its human shuts the laptop — one quiet fact, one exact detail, under 200 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes one line to `out/entry.txt` (45 characters, no trailing newline):

> laptop closed. your download is still at 99%.
